# Outline Beats

- Build plans as cause-and-effect chains, not disconnected ideas.
- A major arc should move through setup, escalation, midpoint pressure, crisis, revelation, climax, and aftermath.
- Each new setting, character, or chapter should support one of these structural jobs: establish normal order, break it, raise stakes, force a decision, or pay off a prior thread.
- When adding content, favor consequences and momentum over encyclopedic explanation.
- If the user asks for a strategic revision, surface how the change affects later beats or faction dynamics.
