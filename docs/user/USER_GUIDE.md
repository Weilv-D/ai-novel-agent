# 用户手册

最后更新：2026-03-17

## 1. 适用对象

本系统面向个人长篇/超长篇创作场景。你可以把它理解为“项目化小说工作台 + Agent 协作编辑器”。

## 2. 首次使用

1. 打开前端页面。
2. 如果实例启用了 `ADMIN_API_KEY`，先在首页保存访问 key。
3. 创建项目，填写名称、题材、目标受众等基础信息。
4. 进入项目详情页，优先整理：
   - 项目大纲 `story_outline`
   - 卷细纲 `Volume.outline`
   - 章节大纲 `Chapter.outline`

## 3. 推荐创作流程

### 3.1 结构搭建

1. 先写项目总纲。
2. 再建立卷。
3. 每卷下补章节。
4. 章节内部拆场景。

### 3.2 对象维护

- 人物页：维护角色档案、关系和备注
- 设定页：维护世界观条目和分类
- 章节页：维护章纲与正文
- 场景页：维护 POV、地点和内容

### 3.3 Agent 协作

在项目详情页的 `Agent Workspace` 中输入自然语言指令，例如：

- “为第一卷补一份三章结构”
- “创建一个反派人物”
- “把第二章改成雨夜追踪氛围”
- “检查当前世界观和人物关系是否冲突”

Agent 会先返回计划和预览，不会直接改数据。你确认后才会执行写入。

## 4. 富文本编辑器

章节与场景编辑页支持 TipTap 富文本编辑：

- 直接输入正文
- 选中文本后触发 Bubble Menu
- 可执行改写、扩写、缩写、换视角
- 保存后内容会以 HTML 存储，导出时自动转纯文本

## 5. 拖拽排序

- 章节页支持卷内章节重排
- 章节详情页支持场景重排

拖拽后顺序会持久化到后端；刷新页面后应保持一致。

## 6. 图谱与时间线

### 6.1 关系图谱

- 图谱页展示人物关系与依赖关系
- 支持缩放、居中和布局切换

### 6.2 时间线

- 时间线页按章节顺序展示事件记忆
- 若 `memory.meta` 中带有 `chapter_id` / `scene_id` 等信息，事件会自动挂接到对应章/场景
- 无法识别归属的事件会落入“游离事件”

## 7. 导出与项目包

### 7.1 内容导出

支持：

- TXT
- Markdown
- DOCX

### 7.2 项目包

- 可导出完整项目包
- 可导入为新项目副本
- 适合迁移、备份和恢复

## 8. 常见问题

### 为什么 Agent 需要二次确认？

当系统判定为高风险正文覆盖或多对象联动重写时，会要求二次确认。

### 为什么时间线里有“游离事件”？

说明事件记忆没有足够的章节/场景定位信息。补齐 `memory.meta` 后可重新归档。

### 为什么导出的 TXT 没有富文本样式？

TXT/Markdown/DOCX 会输出清洗后的文本结构，不保留编辑器内部 HTML 样式。
